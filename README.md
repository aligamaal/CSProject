# For our CS2 class for the first time it was required to develop a simple social media platform. We imitated a version of Spotify, where you can create an account, add friends, and share posts with them. The backend is written in C++ using Crow (a web framework) and we implemented our own AVL trees to store each user's friend list. When you open your timeline, you see your posts mixed with your friends' posts in order by time. We also added a search feature where you can find users without searching for their entire username, only using prefixes. The app suggests friends based on the number of mutual friends you both have. Despite only having very limited time and no prior experience, we were very proud of what we were able to achieve. This project helped us practice many aspects of coding as we used several data structures including trees, vectors and maps, we also used object oriented programming. We were also able to get an insight on front end programming.
